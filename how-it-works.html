How CodeWinnow works

The detector builds two fingerprint streams – one from raw lexical tokens, another from an AST‑normalised view – then compares the sets with Jaccard similarity.

Detection pipeline

  1. Token stream: tokenize strips comments/whitespace and returns tokens like NAME:def.
  2. AST stream: ast.parse produces a tree; identifiers become NAME and literals become CONST:type.
  3. Rolling hash: a Rabin‑Karp polynomial hash is computed for every k‑gram (automatic k=3–9 based on token count; capped for tiny inputs).
  4. Winnowing: a sliding window of size window (default 4) selects the right‑most minimum hash as a fingerprint.
  5. Similarity: Jaccard similarity = |A∩B| / |A∪B| for the two fingerprint sets.

Token vs AST mode

Scenario Token AST
Exact copy‑paste Very high Very high
Renamed variables Medium High
Changed constants Medium High
Comments/whitespace only High High
Control‑flow rewrite Low Medium
Different programs Low Low

Sample programs to try

1. Renamed variables (token medium, AST high)

def count_even(values):
    total = 0
    for value in values:
        if value % 2 == 0:
            total += 1
    return total
def number_of_evens(items):
    answer = 0
    for item in items:
        if item % 2 == 0:
            answer += 1
    return answer

2. Added comments (both high)

def sum_squares(n):

        result += i * i
    return result
def sum_squares(n):
    # initialise accumulator
    result = 0
    # loop through each index
    for i in range(n):
        result += i * i  # square it
    return result  # done

3. Different constants (token medium, AST high)

def clamp(x):

        return 0
    if x > 100:
        return 100
    return x
def clamp(x):
    if x < -255:
        return -255

4. Unrelated programs (both low)

def count_even(values):
    total = 0
    for v in values:
        if v % 2 == 0:
            total += 1
    return total
def reverse_words(sentence):
    words = sentence.split()
    return " ".join(reversed(words))

5. Refactored logic (token low, AST medium)

def squares(nums):
    result = []
    for n in nums:
        result.append(n * n)
    return result
def squares(nums):
    return [n * n for n in nums]

Running the detector

  • Web UI: python -m plagiarism_detector.web then open http://127.0.0.1:8000.
  • CLI compare: python -m plagiarism_detector compare file_a.py file_b.py
  • Evaluation on a JSON pair list: python -m plagiarism_detector evaluate examples/pairs.json
